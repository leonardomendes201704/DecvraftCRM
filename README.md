# White-label ERP/CRM

Plataforma ERP/CRM white-label, modular, auto instalavel, versionavel e escalavel, com foco inicial em .NET 8, ASP.NET Core Web API, Docker, SQL Server, Entity Framework Core e Provisioning Engine.
